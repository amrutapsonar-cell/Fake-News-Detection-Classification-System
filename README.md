# Fake News Detection & Classification System

## Overview
This project uses Machine Learning / Natural Language Processing (NLP) techniques to classify news articles and statements as real or fake.

## Features
- Preprocesses text data (tokenization, stop-word removal, vectorization).
- Trains classification models to distinguish between misleading and authentic information.
- Provides predictions based on input text.
